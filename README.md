# PHELAT Tap

## How do I install these formulae?

`brew install phelat/tap/<formula>`

Or `brew tap phelat/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "phelat/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
